# MegaProxyTools

## Установка и первый запуск

Нужны Git, Python 3.9+ и POSIX shell. Зависимостей pip и фоновых служб нет.

```sh
git clone https://github.com/andre487/MegaProxyTools.git
cd MegaProxyTools
./install.sh
proxy487 --init
${EDITOR:-vi} ~/.proxy487/proxy-list.txt
proxy487 curl https://example.com
noproxy487 curl https://example.com
```

Добавьте `~/.local/bin` в PATH. Для другого каталога: `PREFIX=/path ./install.sh`.
После обновления повторите установку; для удаления удалите два установленных скрипта.
Настройки `~/.proxy487` из dotfiles сохраняются. Проверьте `command -v proxy487`:
старые копии раньше в PATH должны быть удалены или заменены переходными обёртками.

## Настройка

Один URL на строку: `https://USER:ENCODED_PASSWORD@proxy.example.com:443`.
Пароль и логин кодируйте как компоненты URL. Файл содержит секреты: не публикуйте его.
`--init` создаёт файл с правами 0600 и не перезаписывает существующий.
Пустые строки и отдельные строки-комментарии `#` пропускаются.
Поддерживаются `http`, `https`, `socks5`, `socks5h` с обязательным портом.
Поддержка конкретного протокола зависит от запускаемой программы.
Query и fragment удаляются как метаданные экспортированных профилей.
Первым выбирается первый URL; файл `chosen` может содержать hostname нужного proxy.
Отсутствующий hostname и некорректный URL приводят к ошибке до запуска команды.

`proxy487 [--] КОМАНДА [АРГУМЕНТЫ]` назначает HTTP_PROXY, HTTPS_PROXY, ALL_PROXY,
WS_PROXY и WSS_PROXY в обоих регистрах только дочернему процессу.
Существующий `no_proxy` приоритетнее `NO_PROXY`; без них используются localhost,
loopback и 192.168/16. Поддержка CIDR зависит от клиента. Пустой явный список сохраняется.
Остальные частные сети автоматически не исключаются.

`noproxy487` удаляет эти переменные и NO_PROXY в любом регистре. Настройки самого
приложения, системные proxy и VPN остаются действовать.
Аргументы, сигналы и код возврата сохраняются через exec. Родительская оболочка не меняется.
`--help` работает без настройки. `https://` в URL означает TLS до proxy; имя переменной
HTTPS_PROXY описывает целевой трафик, а не протокол соединения с proxy.

## Проверка транспорта и разработка

Успешный HTTPS-запрос не подтверждает работу WebSocket.
Не публикуйте URL с паролями и дампы окружения.

```sh
python3 -m unittest discover -s tests -v
sh -n install.sh
```

## Необязательные переменные окружения

Файл `~/.proxy487/default.env` задаёт значения по умолчанию для `proxy487`:

```dotenv
GODEBUG=http2client=0
```

Формат: буквальные строки `NAME=VALUE`. Пустые строки и строки-комментарии `#` пропускаются.
Пробелы по краям имён и значений удаляются. Кавычки, `export`, подстановки и команды shell
не интерпретируются. Существующее окружение приоритетнее значений файла; адреса proxy
всегда берутся из выбранного профиля. Некорректная запись останавливает запуск команды.
Файл необязателен; `noproxy487` его не загружает. Для секретов используйте права 600.
